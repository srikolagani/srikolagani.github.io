# srikolagani.github.io

Personal notes site — calm editorial layout for write-ups on agentic CRM patterns, evals, and [crm-agent-kit](https://github.com/srikolagani/crm-agent-kit).

## Develop

```bash
npm install
npm run dev
```

## Build / Pages

GitHub Actions builds with Vite and deploys `dist/` to GitHub Pages on push to `main`.

```bash
npm run build
npm run preview
```

Public URL: https://srikolagani.github.io/
